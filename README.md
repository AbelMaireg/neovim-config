# Neovim Config

## Overview
This Neovim configuration is extended from the NVChad base, offering a powerful and highly customizable environment for developers. It leverages modern plugins and configurations to enhance productivity and the overall coding experience.

## Features
- **NVChad Base**: Built on top of NVChad, a modular and highly extensible Neovim configuration.
- **Avante Plugin**: AI-powered assistance integrated with Copilot provider for coding suggestions and completions.
- **Markdown Rendering**: Supports markdown rendering and editing for "markdown" and "Avante" file types.
- **Enhanced LSP Support**: Advanced configurations for Language Server Protocol (LSP), tailored for various programming languages.
- **Advanced Mappings**: Custom keybindings to streamline workflows and improve efficiency.
- **Plugin Highlights**:
  - **Copilot**: AI-driven code suggestions.
  - **Noice**: Enhanced notifications and UI elements.

## Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/nvim-config.git ~/.config/nvim
   ```
2. Install NVChad as the base configuration:
   ```bash
   git clone https://github.com/NvChad/NvChad ~/.config/nvim
   ```
3. Launch Neovim and run the following to install plugins:
   ```bash
   :Lazy install
   ```

## Usage
- Open Neovim and start coding with AI-powered suggestions and completions by Avante.
- Use custom mappings to navigate and edit files efficiently.
- Take advantage of markdown rendering for documentation tasks.
